Step 02 — Build it so it survives

The reliable-agent playbook for product managers.

The frameworks are the power tools; agent-blueprint is the blueprint and the building code. 18 Claude Code skills that turn an idea into a shippable, eval-gated PRD. Framework-agnostic. It specs and decides — it does not lock you into a runtime.

The five questions that decide if an agent ships — and that generic PRDs skip:

01

How will we know it works? (eval plan)

02

What can it do without a human? (HITL)

03

What does it remember? (memory)

04

How does it fail? (premortem)

05

How does it get better? (learning loop)

18 skills, three layers — gates decide, sections write, the spine assembles & audits:
